Geospatial Intelligence via PostGIS

How we perform millisecond-level location searches at scale.

Spatial Geometry Logic

PostGIS stores coordinate metrics natively inside our Postgres db tables, converting standard coordinates into geometry vectors.

  • Natively measures true ellipsoidal ground distances.
  • Triggers accurate searches across variable curves.

Optimized Index Matching

Flyway V7 adds a custom GiST spatial expression index over coordinates.

-- Spatial query execution SELECT l.* FROM listings l WHERE ST_DWithin(l.coords, ST_MakePoint(?1, ?2), ?3)
  • ST_DWithin limits spatial scans in milliseconds.
  • Haversine math sorts nearest results dynamically.

Security & Authentication

Securing users and payments without compromising on API scaling.

Secure OTP Signup

Verifies signups and password changes using unique codes.

  • DB-backed OTP table tracking token reuse.
  • 5-minute validation TTL with auto-cleaning.
  • Email delivery via safe EmailJS requests.

Stateless JWT

Maintains authorization without database lookup chains on every REST call.

  • JWT tokens injected inside Request headers.
  • Signed using custom server cryptographic secrets.
  • Zero state stored on the server memory.

Spring Security

Granular URL matching intercepting unauthorized operations.

  • Restricts CRUD endpoints to verified listing creators.
  • Robust CORS filters blocking suspicious domains.
  • Passwords stored with secure hash models.
